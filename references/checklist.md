# 纳米出版断言-证据自检清单（逐项打钩）

## 拆得细（机制 A）
- [ ] 每条断言只承载一个可独立判断真假的命题
- [ ] 复合句按并列/因果/转折拆开，未把多点塞进一条
- [ ] 条件、范围、限定词、否定、量词原样保留，未加强/削弱
- [ ] 每条断言分配唯一 `claim_id`
- [ ] 主体是材料真实对象，未凭常识补造

## 对得上（机制 C）
- [ ] 每条断言绑定最小充分证据片段（最短连续原文）
- [ ] 证据片段标注原文位置（段落ID/章节/图表号/公式号）
- [ ] 证据区分 `direct`/`indirect`，间接未冒充直接
- [ ] 找不到支撑的断言标 `unsupported` 并进 `human_review_items`
- [ ] 主体、关系类型（受控词表）、方向均与原文一致

## 追得回（机制 E）
- [ ] 来源链含论文标识/作者/年份/版本/数据来源/标识符
- [ ] 跨论文元数据未混用，缺项标 `unverified`
- [ ] 位置用材料给出的段落 ID，未冒充 PDF 页码
- [ ] 他人可据来源链回到原文逐条确认

## 读得懂（机制 B）
- [ ] 字段名/类型/标识符符合 `nanopub_fields.md`
- [ ] 关系类型来自受控词表，越界用 `other`+原文
- [ ] result.json 可被 JSON.parse 解析
- [ ] 无自定义字段导致下游需人工清洗

## 结构与边界
- [ ] `status` 诚实（success/partial/blocked）
- [ ] partial/blocked 写明原因与缺口
- [ ] 材料缺失/无法判断/运行失败分别说明
- [ ] 未编造来源元数据与 benchmark 分数
- [ ] 拆解与核验分离完成，所有改动有 `change_log`
