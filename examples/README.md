# 示例目录说明（生态贡献）

本目录提供一组**演示接口用、非真实案例**的最小调用示例，用于说明输入/输出契约与字段含义。

- `example_input.json`：虚构输入，含 `case_id` 与 `note`（注明"演示接口用，非官方案例"）。
- `example_output.json`：虚构输出，含 `case_id`、`status`、`artifact`（断言-证据单元）、`claim_evidence_map`、`provenance_chain`、`quality_check`、`uncertainties`、`human_review_items`、`change_log`、`self_check`，并标注为示意。

**重要**：示例中的论文、作者、数值、DOI 均为占位/虚构，不代表任何真实论文结论，也不构成预制作答答案或 benchmark 分数。正式案例、白板与对照结果由平台提供，参赛作品不得自带。请将本目录与 `references/nanopub_fields.md` 配合阅读，以正确填写字段。
